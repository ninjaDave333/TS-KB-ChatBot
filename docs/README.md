## 📖 Documentation Standards

### File Naming
- Use kebab-case: `my-document.md`
- Descriptive names: `MCP-Integration-Plan.md` not `plan.md`
- Version in filename if needed: `schema-v2.3.0.md`

### Content Structure
- Start with title and metadata (version, date, status)
- Include table of contents for long docs
- Use clear headings and sections
- Add code examples where relevant
- Include success criteria and metrics

### Maintenance
- Update `Last Updated` date when modified
- Move outdated docs to `/Archive`
- Keep CHANGELOG.md current
- Review quarterly for accuracy
